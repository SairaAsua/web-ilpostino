# Selected visual assets

The postal landscape and original mark were already selected in this repository
at `b627a14414f30adb52f12b6a97469bac4f0d2275`. Original PNG files are retained
unchanged. The WebP derivatives only resize/compress those same compositions for
delivery; dimensions, source/output hashes and sizes are recorded in
`IMAGE-SOURCES.json`. No new person, testimonial or live-home image is invented.
The fictional journal card is authored HTML/CSS, labelled as fiction.

Inter and Playfair Display were the named families in the original design.
They now load from local, unmodified Google Fonts files. The retrieved upstream
URLs and verified Git blob/SHA256 values are in `FONT-SOURCES.json`.
`public/fonts/inter-OFL.txt` and `public/fonts/playfairdisplay-OFL.txt` retain
upstream copyright notices and SIL Open Font License text. Those notices accompany
editable campaign files. The envelope favicon is simple authored SVG geometry;
the original illustrated mark remains on the story page.

Homemaker is credited to Annie and Oliva in the product copy. Its renderer,
private source, catalog assets and authenticated workshop are not copied into the
marketing bundle. The campaign describes its role using source-grounded product
facts and uses Il Postino's selected postal assets.
